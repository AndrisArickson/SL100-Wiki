# Conversion notes accepted (15 Oct 2026)

Every Conversion note that was in `05 New Star Wars - Careers (revised).md` before 15 Oct 2026, with what was done with it.
The ruling was to accept the notes and take the alternatives they suggested. Where a note offered two directions, the one that fits the
career's theme was taken. After this pass the notes were removed from the chapter and every career's status tag became `[sl100]`.

Resolutions:

- **Accepted (already in the text)**: the note describes a change that was already made.
- **Alternative taken**: the change the note suggested has now been made.
- **Accepted as written**: the note offered an option, but the text was kept.
- **Dropped**: the note was overtaken by a later ruling.
- **Moot / Superseded**: a 15 Oct ruling made the note irrelevant (Datapad Use no longer a career talent; weapon groups).

Some suggested changes depended on weapon-skill choices; those were done together with the weapon-skill pass in
[weapon-skills-2026-10-15.md](weapon-skills-2026-10-15.md).
